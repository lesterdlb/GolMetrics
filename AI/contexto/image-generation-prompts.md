# Usage Tips by Platform

## 🎨 Midjourney

**Best practices:**

-   Use the **Midjourney Version** prompts provided above
-   Add aspect ratio: `--ar 9:16` (mobile) or `--ar 16:9` (desktop)
-   Use `--style raw` to avoid over-stylization
-   Use `--q 2` for higher quality
-   Example: `[prompt] --ar 9:16 --v 6 --style raw --q 2`

**Parameters to try:**

-   `--v 6` or `--v 6.1` (latest version)
-   `--style raw` (more literal interpretation)
-   `--s 250` (medium stylization, 0-1000 scale)

## 🤖 DALL-E 3 (ChatGPT)

**Best practices:**

-   Use the **Full Version** or **Detailed UI Version**
-   DALL-E 3 understands complex, natural language descriptions
-   Be specific about text you want in the image
-   Don't use parameters (--ar, etc.) - just natural language

**Example usage:**

```
Generate an image using this prompt: [paste Full Version here]
```

## 🎯 Ideogram

**Best practices:**

-   **Excellent for text in images** - specify exact text clearly
-   Use **Short Version** or **Full Version**
-   Ideogram handles UI text better than most tools
-   Specify "realistic UI mockup" for better results

**Example addition:**

```
[Full Version prompt] + "Include realistic UI text, professional mockup quality, trending on Behance"
```

## 🖼️ Stable Diffusion (Automatic1111, ComfyUI)

**Best practices:**

-   Use **Short Version** or **Full Version**
-   Add quality boosters at the end
-   Use negative prompts to avoid unwanted elements

**Quality boosters to add:**

```
, trending on Dribbble, award winning UI design, Behance featured, professional mockup, 8k resolution, highly detailed, clean interface
```

**Negative prompts:**

```
blurry, low quality, distorted, ugly, amateur, pixelated, messy, cluttered
```

## 📱 Leonardo.ai

**Best practices:**

-   Use **Full Version** prompts
-   Select "3D Render" or "Creative" preset for UI designs
-   Increase "Prompt Magic" slider for better adherence
-   Use "PhotoReal" mode for realistic mockups

## 🔄 Iteration Tips

1. **Start simple**: Begin with Short Version to test concept
2. **Refine details**: Use Full Version once you like the direction
3. **Specific elements**: Use Detailed UI Version for final mockups
4. **Generate variations**:
    - Change color schemes: "Use purple instead of green"
    - Adjust layouts: "Show landscape orientation"
    - Modify elements: "Make cards larger and more prominent"

## 🎯 Recommended Workflow

1. Generate with **Short Version** (quick test)
2. Pick best concept
3. Regenerate with **Full Version** (more detail)
4. Fine-tune with **Detailed UI Version**
5. Create variations by modifying specific elements
